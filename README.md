# Comanda Digital - Funcionalidade de Exclusão

Este repositório contém a implementação completa da funcionalidade de **Exclusão em Massa** para pedidos e produtos, abrangendo:

1. **Frontend Android** (Jetpack Compose, ViewModel, Retrofit)
2. **Backend Node.js** (Express routes)
3. **Backend Spring Boot** (Controllers)
4. **Web Admin** (React.jsx e botão em HTML puro para o painel)

## Como utilizar:
Basta copiar os respectivos diretórios para as pastas correspondentes do seu projeto principal e realizar o commit para o GitHub.
